# Data sources

Software needs data. These providers publish data that works with the tools in this catalog. This site lists software only and does not host data.

## Basemaps and boundaries

- [Natural Earth](https://www.naturalearthdata.com/) provides public domain world boundaries, coastlines and places at several scales.
- [OpenStreetMap](https://www.openstreetmap.org/copyright) data is available under the ODbL. [Geofabrik](https://download.geofabrik.de/) publishes regional extracts.
- [Overture Maps](https://overturemaps.org/) publishes open map data in GeoParquet.
- [US Census TIGER/Line](https://www.census.gov/geographies/mapping-files/time-series/geo/tiger-line-file.html) provides US boundaries and roads.
- [GADM](https://gadm.org/) provides global administrative areas. Check its license before redistributing.

## Imagery and Earth observation

- [Copernicus Data Space Ecosystem](https://dataspace.copernicus.eu/) serves Sentinel data.
- [USGS EarthExplorer](https://earthexplorer.usgs.gov/) serves Landsat and other USGS archives.
- [NASA Earthdata](https://www.earthdata.nasa.gov/) serves MODIS, VIIRS and many other NASA products.
- [Microsoft Planetary Computer](https://planetarycomputer.microsoft.com/catalog) and the [AWS Open Data registry](https://registry.opendata.aws/) host cloud-optimized archives.
- [Google Earth Engine data catalog](https://developers.google.com/earth-engine/datasets) lists datasets available in Earth Engine.

## Reference

- [EPSG.io](https://epsg.io/) and [spatialreference.org](https://spatialreference.org/) look up coordinate reference systems.

## Fire data

The sister catalog [Awesome Fire Datasets](https://noahweidig.github.io/awesome-fire-data/) lists datasets for fire science, with perimeters, active fire, fuels and weather.
