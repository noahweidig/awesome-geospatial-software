# OpenStreetMap tools

Editors, extract tools, importers and query services for OpenStreetMap data.

<div class="grid cards" markdown>

-   :lucide-map-pinned:{ .lg .middle } __[iD](id-editor.md)__

    ---

    Browser-based OpenStreetMap editor and the default editor on openstreetmap.org.

    [:lucide-arrow-right: Details](id-editor.md)

-   ![](../../assets/logos/josm.png){ .logo .middle } __[JOSM](josm.md)__

    ---

    Java OpenStreetMap editor for advanced mapping, with plugins, imagery layers, validation and offline editing.

    [:lucide-arrow-right: Details](josm.md)

-   :lucide-map-pinned:{ .lg .middle } __[OpenStreetMap Carto](openstreetmap-carto.md)__

    ---

    CartoCSS stylesheet and Mapnik toolchain behind the standard map layer on openstreetmap.org.

    [:lucide-arrow-right: Details](openstreetmap-carto.md)

-   ![](../../assets/logos/osm2pgsql.png){ .logo .middle } __[osm2pgsql](osm2pgsql.md)__

    ---

    Imports OpenStreetMap data into a PostGIS database, with flexible Lua-based styling of tables and support for minutely updates.

    [:lucide-arrow-right: Details](osm2pgsql.md)

-   :lucide-map-pinned:{ .lg .middle } __[Osmium Tool](osmium-tool.md)__

    ---

    Command line tool for filtering, extracting, merging and converting OpenStreetMap data files, built on libosmium.

    [:lucide-arrow-right: Details](osmium-tool.md)

-   :lucide-map-pinned:{ .lg .middle } __[Osmosis](osmosis.md)__

    ---

    Java command line tool for processing OpenStreetMap data, including filtering, merging and applying change files.

    [:lucide-arrow-right: Details](osmosis.md)

-   :lucide-map-pinned:{ .lg .middle } __[Overpass API](overpass-api.md)__

    ---

    Read-only API for querying OpenStreetMap data with a custom query language, with public instances and an Overpass Turbo web interface.

    [:lucide-arrow-right: Details](overpass-api.md)

-   :lucide-map-pinned:{ .lg .middle } __[Overpass Turbo](overpass-turbo.md)__

    ---

    Web-based data mining tool that runs Overpass queries and shows results on a map, with export to GeoJSON, GPX and KML.

    [:lucide-arrow-right: Details](overpass-turbo.md)

-   ![](../../assets/logos/quackosm.png){ .logo .middle } __[QuackOSM](quackosm.md)__

    ---

    Python tool that reads OpenStreetMap PBF files with DuckDB and writes GeoParquet, without a database server.

    [:lucide-arrow-right: Details](quackosm.md)

-   ![](../../assets/logos/streetcomplete.png){ .logo .middle } __[StreetComplete](streetcomplete.md)__

    ---

    Android app that improves OpenStreetMap by asking simple survey questions about places near you.

    [:lucide-arrow-right: Details](streetcomplete.md)

</div>
