# Data conversion, ETL & catalogs

Format conversion, spatial ETL, metadata catalogs and spatial data infrastructure.

<div class="grid cards" markdown>

-   ![](../../assets/logos/esri-data-interoperability.png){ .logo .middle } __[ArcGIS Data Interoperability](esri-data-interoperability.md)__

    ---

    Esri extension, powered by FME technology, for reading, transforming and writing spatial data in many formats within ArcGIS Pro.

    [:lucide-arrow-right: Details](esri-data-interoperability.md)

-   ![](../../assets/logos/ckan.png){ .logo .middle } __[CKAN](ckan.md)__

    ---

    Open source data portal platform with spatial extensions for searching and previewing geospatial datasets.

    [:lucide-arrow-right: Details](ckan.md)

-   ![](../../assets/logos/fme.png){ .logo .middle } __[FME](fme.md)__

    ---

    Commercial spatial ETL platform with a visual workflow builder that converts and transforms hundreds of formats and automates data pipelines.

    [:lucide-arrow-right: Details](fme.md)

-   ![](../../assets/logos/geonetwork.png){ .logo .middle } __[GeoNetwork opensource](geonetwork.md)__

    ---

    Catalog application for managing spatial metadata, with ISO 19115 editing, harvesting, CSW and OGC API Records interfaces.

    [:lucide-arrow-right: Details](geonetwork.md)

-   ![](../../assets/logos/geonode.png){ .logo .middle } __[GeoNode](geonode.md)__

    ---

    Geospatial content management system and spatial data infrastructure platform for publishing, sharing and styling data and maps.

    [:lucide-arrow-right: Details](geonode.md)

-   :lucide-arrow-left-right:{ .lg .middle } __[gpq](gpq.md)__

    ---

    Command line utility that converts between GeoParquet and GeoJSON and validates GeoParquet files.

    [:lucide-arrow-right: Details](gpq.md)

-   ![](../../assets/logos/hale-studio.png){ .logo .middle } __[HALE Studio](hale-studio.md)__

    ---

    Open source tool for defining schema mappings and transforming geospatial data to INSPIRE and other target models.

    [:lucide-arrow-right: Details](hale-studio.md)

-   ![](../../assets/logos/ogr2ogr.png){ .logo .middle } __[ogr2ogr](ogr2ogr.md)__

    ---

    GDAL command line program that converts vector data between formats, reprojects, filters with SQL and loads data into databases.

    [:lucide-arrow-right: Details](ogr2ogr.md)

-   ![](../../assets/logos/pycsw.png){ .logo .middle } __[pycsw](pycsw.md)__

    ---

    Python server for publishing metadata and catalogs through OGC CSW, OGC API Records, OpenSearch and STAC.

    [:lucide-arrow-right: Details](pycsw.md)

-   :lucide-arrow-left-right:{ .lg .middle } __[pygeometa](pygeometa.md)__

    ---

    Python library for generating geospatial metadata in ISO 19139, OGC API Records and STAC from a simple configuration file.

    [:lucide-arrow-right: Details](pygeometa.md)

</div>
