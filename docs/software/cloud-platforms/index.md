# Cloud platforms & location APIs

Hosted analysis platforms, data catalogs and commercial map, search and routing APIs.

<div class="grid cards" markdown>

-   ![](../../assets/logos/aws-location-service.png){ .logo .middle } __[Amazon Location Service](aws-location-service.md)__

    ---

    AWS service for maps, places, geocoding, routing and device tracking using data from partners such as Esri, HERE and Grab.

    [:lucide-arrow-right: Details](aws-location-service.md)

-   ![](../../assets/logos/arcgis-online.png){ .logo .middle } __[ArcGIS Online](arcgis-online.md)__

    ---

    Esri's hosted GIS for creating and sharing maps, apps, dashboards and layers, with analysis tools and the Living Atlas of content.

    [:lucide-arrow-right: Details](arcgis-online.md)

-   ![](../../assets/logos/azure-maps.png){ .logo .middle } __[Azure Maps](azure-maps.md)__

    ---

    Microsoft Azure map rendering, search, routing, weather and spatial operations APIs with web and mobile SDKs.

    [:lucide-arrow-right: Details](azure-maps.md)

-   ![](../../assets/logos/carto.png){ .logo .middle } __[CARTO](carto.md)__

    ---

    Cloud-native location intelligence platform that runs spatial analysis in data warehouses such as BigQuery, Snowflake and Databricks and builds web maps.

    [:lucide-arrow-right: Details](carto.md)

-   ![](../../assets/logos/felt.png){ .logo .middle } __[Felt](felt.md)__

    ---

    Browser-based collaborative mapping tool for uploading data, styling layers, drawing and sharing maps.

    [:lucide-arrow-right: Details](felt.md)

-   ![](../../assets/logos/foursquare-studio.png){ .logo .middle } __[Foursquare Studio](foursquare-studio.md)__

    ---

    Hosted map studio built on kepler.gl and deck.gl for visualizing and sharing large geospatial datasets.

    [:lucide-arrow-right: Details](foursquare-studio.md)

-   ![](../../assets/logos/mapbox.png){ .logo .middle } __[Mapbox](mapbox.md)__

    ---

    Hosted maps, tilesets, geocoding, directions and navigation APIs with Mapbox Studio for styling.

    [:lucide-arrow-right: Details](mapbox.md)

-   :lucide-cloud:{ .lg .middle } __[Mapillary](mapillary.md)__

    ---

    Platform for street-level imagery collected by contributors, with APIs and an SDK, and map features derived from the photos.

    [:lucide-arrow-right: Details](mapillary.md)

-   ![](../../assets/logos/maptiler-cloud.png){ .logo .middle } __[MapTiler Cloud](maptiler-cloud.md)__

    ---

    Hosted vector and raster maps, geocoding, elevation and tile hosting with a MapLibre-compatible API.

    [:lucide-arrow-right: Details](maptiler-cloud.md)

-   ![](../../assets/logos/nasa-worldview.png){ .logo .middle } __[NASA Worldview](nasa-worldview.md)__

    ---

    Interactive web viewer for NASA satellite imagery layers with time animation, comparison and data download links.

    [:lucide-arrow-right: Details](nasa-worldview.md)

-   ![](../../assets/logos/planet-platform.png){ .logo .middle } __[Planet Platform](planet-platform.md)__

    ---

    Commercial satellite imagery and analytics platform with daily PlanetScope and SkySat imagery, APIs and a Python client.

    [:lucide-arrow-right: Details](planet-platform.md)

-   ![](../../assets/logos/stadia-maps.png){ .logo .middle } __[Stadia Maps](stadia-maps.md)__

    ---

    Hosted map tiles, geocoding and routing APIs built on open source engines such as Valhalla and Pelias.

    [:lucide-arrow-right: Details](stadia-maps.md)

-   ![](../../assets/logos/up42.png){ .logo .middle } __[UP42](up42.md)__

    ---

    Marketplace and developer platform for geospatial data and processing workflows, including satellite imagery and analytics.

    [:lucide-arrow-right: Details](up42.md)

</div>
