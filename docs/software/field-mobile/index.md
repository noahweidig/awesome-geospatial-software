# Field collection & mobile

Mobile apps and survey tools for collecting, editing and viewing spatial data in the field.

<div class="grid cards" markdown>

-   ![](../../assets/logos/arcgis-field-maps.png){ .logo .middle } __[ArcGIS Field Maps](arcgis-field-maps.md)__

    ---

    Esri's mobile app for field mapping, data collection, navigation and location tracking connected to ArcGIS.

    [:lucide-arrow-right: Details](arcgis-field-maps.md)

-   ![](../../assets/logos/arcgis-survey123.png){ .logo .middle } __[ArcGIS Survey123](arcgis-survey123.md)__

    ---

    Form-centric survey tool from Esri based on XLSForm, for collecting and analyzing location-aware surveys on web and mobile.

    [:lucide-arrow-right: Details](arcgis-survey123.md)

-   :lucide-smartphone:{ .lg .middle } __[Avenza Maps](avenza-maps.md)__

    ---

    Offline map viewer for Android and iOS that opens georeferenced PDFs and GeoTIFFs and records GPS tracks.

    [:lucide-arrow-right: Details](avenza-maps.md)

-   ![](../../assets/logos/mapeo.png){ .logo .middle } __[CoMapeo](mapeo.md)__

    ---

    Offline, peer-to-peer mapping app for community mapping and monitoring, from Digital Democracy.

    [:lucide-arrow-right: Details](mapeo.md)

-   ![](../../assets/logos/epicollect5.png){ .logo .middle } __[Epicollect5](epicollect5.md)__

    ---

    Free mobile and web data collection platform from Imperial College London for building forms with GPS fields and viewing maps.

    [:lucide-arrow-right: Details](epicollect5.md)

-   ![](../../assets/logos/geopaparazzi.png){ .logo .middle } __[Geopaparazzi](geopaparazzi.md)__

    ---

    Android app for digital field mapping with notes, photos, GPS logs and offline basemaps, with a desktop companion in gvSIG and QGIS.

    [:lucide-arrow-right: Details](geopaparazzi.md)

-   ![](../../assets/logos/kobotoolbox.png){ .logo .middle } __[KoboToolbox](kobotoolbox.md)__

    ---

    Free platform for field data collection built on ODK-compatible forms, widely used by humanitarian organizations.

    [:lucide-arrow-right: Details](kobotoolbox.md)

-   ![](../../assets/logos/mergin-maps.png){ .logo .middle } __[Mergin Maps](mergin-maps.md)__

    ---

    Field data collection app and sync service built on QGIS, with a mobile app, QGIS plugin and cloud sync.

    [:lucide-arrow-right: Details](mergin-maps.md)

-   :lucide-smartphone:{ .lg .middle } __[ODK](odk.md)__

    ---

    Open source tools for building forms, collecting data on Android devices and managing submissions, with GPS and map questions.

    [:lucide-arrow-right: Details](odk.md)

-   ![](../../assets/logos/organic-maps.png){ .logo .middle } __[Organic Maps](organic-maps.md)__

    ---

    Offline OpenStreetMap maps and navigation app for Android and iOS with no ads or tracking.

    [:lucide-arrow-right: Details](organic-maps.md)

-   ![](../../assets/logos/osmand.png){ .logo .middle } __[OsmAnd](osmand.md)__

    ---

    Offline OpenStreetMap navigation and map app for Android and iOS with vector maps, routing and GPX recording.

    [:lucide-arrow-right: Details](osmand.md)

-   ![](../../assets/logos/qfield.png){ .logo .middle } __[QField](qfield.md)__

    ---

    Mobile field GIS for Android, iOS and Windows that opens QGIS projects offline, for data collection, editing and navigation.

    [:lucide-arrow-right: Details](qfield.md)

-   :lucide-smartphone:{ .lg .middle } __[SW Maps](sw-maps.md)__

    ---

    Free Android and iOS app for GIS data collection and navigation with external GNSS receivers over Bluetooth.

    [:lucide-arrow-right: Details](sw-maps.md)

</div>
