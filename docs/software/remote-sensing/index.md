# Remote sensing & image analysis

Satellite and aerial image processing, SAR, classification and analysis-ready data tools.

<div class="grid cards" markdown>

-   ![](../../assets/logos/appeears.png){ .logo .middle } __[AppEEARS](appeears.md)__

    ---

    NASA web tool and API for extracting and subsetting Earth observation samples by point or area, from the LP DAAC.

    [:lucide-arrow-right: Details](appeears.md)

-   ![](../../assets/logos/copernicus-data-space.png){ .logo .middle } __[Copernicus Data Space Ecosystem](copernicus-data-space.md)__

    ---

    ESA-backed platform for searching, downloading and processing Copernicus Sentinel data through a browser, STAC, OData and openEO APIs.

    [:lucide-arrow-right: Details](copernicus-data-space.md)

-   ![](../../assets/logos/digital-earth-africa.png){ .logo .middle } __[Digital Earth Africa](digital-earth-africa.md)__

    ---

    Open platform and Python tools for analyzing Earth observation data over Africa, built on Open Data Cube with a sandbox, maps and training.

    [:lucide-arrow-right: Details](digital-earth-africa.md)

-   ![](../../assets/logos/ecognition.png){ .logo .middle } __[eCognition](ecognition.md)__

    ---

    Commercial object-based image analysis software that segments and classifies imagery using rule sets and machine learning.

    [:lucide-arrow-right: Details](ecognition.md)

-   ![](../../assets/logos/envi.png){ .logo .middle } __[ENVI](envi.md)__

    ---

    Commercial image analysis software for multispectral, hyperspectral, SAR and LiDAR data, with IDL scripting and a deep learning module.

    [:lucide-arrow-right: Details](envi.md)

-   :lucide-satellite:{ .lg .middle } __[eo-learn](eo-learn.md)__

    ---

    Python library of workflow tasks for building Earth observation pipelines from data download to machine learning.

    [:lucide-arrow-right: Details](eo-learn.md)

-   :lucide-satellite:{ .lg .middle } __[ERDAS IMAGINE](erdas-imagine.md)__

    ---

    Hexagon's commercial remote sensing and photogrammetry suite for image processing, classification and mapping.

    [:lucide-arrow-right: Details](erdas-imagine.md)

-   :lucide-satellite:{ .lg .middle } __[FORCE](force.md)__

    ---

    Framework for large-area processing of Landsat and Sentinel-2 archives into analysis-ready data, time series and higher-level products.

    [:lucide-arrow-right: Details](force.md)

-   :lucide-satellite:{ .lg .middle } __[GeoWombat](geowombat.md)__

    ---

    Python library for processing satellite imagery and time series with Rasterio and Xarray, including band math, mosaicking and sampling.

    [:lucide-arrow-right: Details](geowombat.md)

-   ![](../../assets/logos/google-earth-engine.png){ .logo .middle } __[Google Earth Engine](google-earth-engine.md)__

    ---

    Cloud platform for planetary-scale analysis with a catalog of satellite imagery and geophysical datasets, a JavaScript Code Editor and Python and R clients.

    [:lucide-arrow-right: Details](google-earth-engine.md)

-   :lucide-satellite:{ .lg .middle } __[ISCE3](isce3.md)__

    ---

    JPL's InSAR scientific computing environment for processing synthetic aperture radar data into interferograms and displacement maps.

    [:lucide-arrow-right: Details](isce3.md)

-   :lucide-satellite:{ .lg .middle } __[Microsoft Planetary Computer](microsoft-planetary-computer.md)__

    ---

    Catalog of open Earth observation datasets in Azure with a STAC API, a data Explorer and a Hub for Python analysis.

    [:lucide-arrow-right: Details](microsoft-planetary-computer.md)

-   :lucide-satellite:{ .lg .middle } __[MintPy](mintpy.md)__

    ---

    Python package for InSAR time series analysis that turns interferograms into surface displacement time series and velocity maps.

    [:lucide-arrow-right: Details](mintpy.md)

-   ![](../../assets/logos/open-data-cube.png){ .logo .middle } __[Open Data Cube](open-data-cube.md)__

    ---

    Python framework for indexing, managing and analyzing large Earth observation archives as multi-dimensional data cubes.

    [:lucide-arrow-right: Details](open-data-cube.md)

-   :lucide-satellite:{ .lg .middle } __[openEO](openeo.md)__

    ---

    Open API and client libraries in Python, R and JavaScript for processing Earth observation data across different cloud back ends.

    [:lucide-arrow-right: Details](openeo.md)

-   ![](../../assets/logos/orfeo-toolbox.png){ .logo .middle } __[Orfeo ToolBox](orfeo-toolbox.md)__

    ---

    Open source library and applications for processing high-resolution optical, SAR and hyperspectral images, with Monteverdi and QGIS integration.

    [:lucide-arrow-right: Details](orfeo-toolbox.md)

-   :lucide-satellite:{ .lg .middle } __[PCI Geomatica](pci-geomatica.md)__

    ---

    Commercial software for satellite and aerial image processing, orthorectification, SAR analysis and automated production workflows.

    [:lucide-arrow-right: Details](pci-geomatica.md)

-   :lucide-satellite:{ .lg .middle } __[pyresample](pyresample.md)__

    ---

    Python package for resampling geospatial image data between swath and area definitions, used by Satpy.

    [:lucide-arrow-right: Details](pyresample.md)

-   :lucide-satellite:{ .lg .middle } __[Satpy](satpy.md)__

    ---

    Python library for reading, resampling, compositing and writing data from weather and Earth observation satellites such as GOES, MSG and VIIRS.

    [:lucide-arrow-right: Details](satpy.md)

-   :lucide-satellite:{ .lg .middle } __[Semi-Automatic Classification Plugin](semi-automatic-classification-plugin.md)__

    ---

    QGIS plugin for downloading, preprocessing and classifying satellite images and assessing accuracy.

    [:lucide-arrow-right: Details](semi-automatic-classification-plugin.md)

-   ![](../../assets/logos/sen2cor.png){ .logo .middle } __[Sen2Cor](sen2cor.md)__

    ---

    ESA processor that performs atmospheric, terrain and cirrus correction of Sentinel-2 Level-1C data to produce Level-2A surface reflectance.

    [:lucide-arrow-right: Details](sen2cor.md)

-   ![](../../assets/logos/sentinel-hub.png){ .logo .middle } __[Sentinel Hub](sentinel-hub.md)__

    ---

    Cloud API and EO Browser for streaming, processing and visualizing Sentinel, Landsat and commercial imagery with custom scripts.

    [:lucide-arrow-right: Details](sentinel-hub.md)

-   :lucide-satellite:{ .lg .middle } __[sentinelhub-py](sentinelhub-py.md)__

    ---

    Python package for the Sentinel Hub API that requests imagery, statistics and batch processing jobs.

    [:lucide-arrow-right: Details](sentinelhub-py.md)

-   ![](../../assets/logos/snap.png){ .logo .middle } __[SNAP](snap.md)__

    ---

    ESA's open source toolbox for Sentinel and other Earth observation data, including the Sentinel-1, Sentinel-2 and Sentinel-3 toolboxes.

    [:lucide-arrow-right: Details](snap.md)

-   :lucide-satellite:{ .lg .middle } __[Spectral Python](spectral-python.md)__

    ---

    Python module for processing hyperspectral image data, including classification, dimensionality reduction and ENVI file support.

    [:lucide-arrow-right: Details](spectral-python.md)

</div>
