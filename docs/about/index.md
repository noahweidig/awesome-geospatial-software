# About

Awesome Geospatial Software is a community catalog of geospatial tools. It lists where software lives and how it is licensed. It does not host the software.

## Scope

Desktop GIS, libraries, servers, databases, cloud platforms and apps for working with spatial data, with open source and commercial products side by side. Pure data catalogs are out of scope. Data sources are listed under [Learn](../learn/data-sources.md).
