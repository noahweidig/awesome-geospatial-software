# awesome-geospatial-software

A curated catalog of geospatial software: desktop GIS, libraries, web mapping, servers, databases, remote sensing and more.

Site: https://noahweidig.github.io/awesome-geospatial-software/

Software entries live in `data/software/*.yml`. See the [Contribute page](https://noahweidig.github.io/awesome-geospatial-software/contribute/) to add one.

```bash
pip install -r requirements.txt
python scripts/generate.py
zensical serve
```
